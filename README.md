# Sage Intacct ERP Project Portfolio

This repository showcases a full ERP implementation lifecycle for Sage Intacct, structured as a reusable project template for future client work.

## Objective

- Demonstrate end-to-end ERP implementation capability.
- Provide reusable templates for requirements, process mapping, configuration, UAT, go-live, and post-go-live support.
- Serve as a portfolio of consulting deliverables for Sage Intacct-focused roles.

## Scope

Modules and processes covered:

- General Ledger
- Accounts Payable
- Accounts Receivable
- Cash Management
- Dimensions
- Projects / Job Costing
- Reporting and Dashboards
- Procure-to-Pay
- Order-to-Cash
- Month-end close

## Structure

Each folder represents a phase of the implementation lifecycle:

1. Project Overview  
2. Requirements Gathering  
3. Current vs Future State  
4. Process Mapping  
5. Configuration Support  
6. Data Migration & Validation  
7. User Acceptance Testing (UAT)  
8. Go-Live Preparation  
9. Cutover  
10. Training & Adoption  
11. Post-Go-Live Support
